## About

I'm a Computer Science & Engineering undergraduate at **American International University-Bangladesh (AIUB)**, graduating in 2026. I'm a co-author on a published paper in the **Journal of Imaging (MDPI)** on bilingual sign language recognition using YOLOv11, and I split my time between machine learning research, full-stack development, and learning Oracle database administration — aiming for banking & IT roles in Bangladesh.

**Currently working on:**
- 🧬 **DCAS-Net** — a dual-branch cross-attention skin disease classifier (EfficientNetB3 + Swin Transformer)
- 🌾 A rice/paddy disease classification ensemble (ResNet18 + EfficientNet-B0, ~97.7% accuracy)
- 🏦 **Bank_Demo_System** — a full-stack Django banking platform
- 🗄️ **Bank_System_Database_SQL_Demo** — an Oracle 19c banking database (PL/SQL, RMAN, unified auditing)
